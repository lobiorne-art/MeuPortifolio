PROJETO 1ºBIM
O projeto do primeiro bimestre proposto buscava o desenvolvimento de um jogo por meio da plataforma Construct 3. A plataforma possui um modo simples de codificação, conhecido como código por blocos, em que se escolhem ações pré-programadas para que algum tipo de ação ocorra. Mesmo com o foco na programação, conseguimos principalmente fazer com que o menu funcionasse perfeitamente. Procurando conectar o tema do jogo com a ODS 11, colocamos o nome de "Failure 11".


PROJETO 2ºBIM
Avançando na área da programação, no segundo bimestre, foi proposta a criação de um aplicativo direcionado para um comércio, necessitando de etapas até atender às devidas necessidades do comerciante. Considerando isso, o grupo escolheu o Mercadinho Ayres como local, realizando uma entrevista para que pudéssemos compreender suas necessidades. Diante da entrevista, fizemos projetos de baixa e média fidelidade e trabalhamos com JavaScript para a construção do aplicativo para os funcionários.


PROJETO 3ºBIM
O trabalho do 3º bimestre era criar um sistema web para reservar laboratórios da escola sem dar choque de horário. Os professores disputam o mesmo laboratório no mesmo horário, então o sistema precisa impedir isso. Assim, foi produzido um banco de dados com duas tabelas interligadas, uma tela em Streamlit mostrando as reservas, utilizando INNER JOIN para aparecer o nome do laboratório em vez do ID, e um formulário que possibilitava reservar com data e turno. Além disso, o sistema identificava quando já existia alguma reserva e bloqueava uma nova, mostrando uma mensagem de erro. Com isso, foi desenvolvido um aplicativo funcional junto de um banco de dados.
